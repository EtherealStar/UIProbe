# 10: 从命令行完成真实模型登录及独立验收

**What to build:** 新使用者按安装说明提供模型配置、启动本地演示页面并运行一条命令，使用严格格式用例完成登录和独立视觉验收，取得机器可读结果及完整本地产物。

**Blocked by:** 03 — 用断言与最终截图完成独立视觉验收；05 — 使用数据引用填写当前焦点并完成登录；06 — 滚动页面及显式等待后取得新观察；07 — 动作额度耗尽后在有界循环内总结提交；08 — 模型只看最新图片而本地保留完整执行证据；09 — 超时取消及阶段故障后释放资源并保留已有结论。

**Status:** ready-for-agent

- [ ] 提供最小命令行装配、严格格式登录及初始观察用例、演示运行配置和安装说明；不猜测或转换旧格式用例。
- [ ] 模型只在应用入口装配并关闭客户端，SessionConfig 不包含第二套模型选择；缺少配置给出安全错误，不启动浏览器。
- [ ] 输出机器可读 SessionResult，passed／failed／error 返回码分别为 0／1／2；产物路径真实存在，执行及验收记录分开，全部截图关联可解析。
- [ ] 离线端到端测试使用真实浏览器、真实模型框架与可控响应验证登录通过、明确断言反例及证据不足，不只模拟 Session。
- [ ] 所有现有及新增回归通过且不需要真实密钥；没有因缺少浏览器而跳过关键测试却宣称完成。
- [ ] 真实模型至少完成一次登录并独立验收通过，以及一次初始观察零动作验收；记录 session_id、模型名、日期和实际产物位置，不保存密钥。
- [ ] 视觉断言仅依赖最终截图可见事实；若真实服务未配置，明确保留本票未完成，不使用模拟证据代替真实演示。
