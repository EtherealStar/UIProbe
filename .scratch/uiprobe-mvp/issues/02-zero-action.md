# 02: 从初始页面观察直接提交零动作会话

**What to build:** 调用方运行一条有效用例，系统打开真实本地页面、保存首张截图，经模型框架返回正常最终文本形成 Submission，并释放浏览器。测试中注入可控验收实现验证 Session 接续，不添加生产假验收入口。

**Blocked by:** 01 — 非法输入返回可追查的会话错误。

**Status:** ready-for-agent

- [ ] 初始 BrowserState 有可解码 PNG、会话内唯一截图编号、实际图片像素及同次 CSS 视口尺寸；固定视口，不裁剪、缩放或拍长图。
- [ ] 使用现有客户端接入模型框架，正常最终文本产生 Submission，不手写循环或替代消息协议。
- [ ] 零动作无需创建 TODO，action_count 为零；验收调用取得初始截图。
- [ ] 执行模型只收到数据引用名；本次运行的初始消息和图片关联在过滤前开始增量记录。
- [ ] 同一 Session 多次运行不串用 Context、页面、计划或历史；浏览器资源释放，借用的模型客户端仍可复用。
- [ ] 真实本地浏览器加可控模型响应的测试证明以上行为；框架消息接合的实际验证结果记录到正式设计或执行决策中。
