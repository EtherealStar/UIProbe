# 06: 滚动页面及显式等待后取得新观察

**What to build:** Agent 可以按 CSS 像素向上或向下滚动页面，也可请求有界等待，再从新截图判断下一步；两种动作均使用现有公共执行路径。

**Blocked by:** 04 — 创建计划后按截图坐标点击并观察结果。

**Status:** ready-for-agent

- [ ] scroll 仅操作页面级垂直滚动，正负方向和 CSS 单位正确，不引入容器查找参数。
- [ ] wait 接受严格正整数毫秒，受单次上限和共享剩余时间约束；非法时长在派发前拒绝且不增加动作数。
- [ ] 两个工具均拒绝字符串、布尔值冒充整数和未知输入字段。
- [ ] 每个成功动作占一次额度、生成一次新观察、保存截图并更新当前图；画面不变仍生成新编号。
- [ ] 操作后不增加隐式固定等待；模型通过 wait 自己决定何时再观察。
- [ ] 可滚动真实本地页面及可控模型／时钟场景验证滚动、等待、截图与记录链路。
