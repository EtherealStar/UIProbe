# 05: 使用数据引用填写当前焦点并完成登录

**What to build:** Agent 通过点击选择账号和密码输入框，再调用 fill_value 引用运行配置中的值，提交本地登录表单并观察首页。模型只选择引用名，不直接提供实际文本。

**Blocked by:** 04 — 创建计划后按截图坐标点击并观察结果。

**Status:** ready-for-agent

- [ ] 从运行配置注入实际值到 Browser，执行模型和工具 schema 只接触引用名。
- [ ] fill_value 覆盖当前焦点输入框已有内容，不追加，不自动寻找或点击替代目标。
- [ ] 未知引用、空引用和可预检的非可填写焦点返回具体可纠正错误，动作数不增加；错误不包含实际值。
- [ ] 填写沿用公共路径的计数、串行操作、单次截图、记录和观察更新；普通事件及工具结果只记录引用名。
- [ ] 真实本地页面加可控模型响应完成点击、填写及提交，首页可见；不以此测试的页面检查替代生产视觉验收。
- [ ] 覆盖填写、无效引用及焦点拒绝场景有行为测试；真实截图仍保存真实页面，不宣称自动脱敏。
