# 07: 动作额度耗尽后在有界循环内总结提交

**What to build:** 最后一个允许动作及截图完成后，Agent 所有工具都不可继续执行，只能在原有框架循环和剩余额度内总结；没有正常最终输出则返回执行错误。

**Blocked by:** 04 — 创建计划后按截图坐标点击并观察结果。

**Status:** ready-for-agent

- [ ] 最后一次动作的截图先完成，再禁用包括 TODO 在内的全部工具；后续模型请求提示总结并不再开放工具。
- [ ] 同一响应中剩余工具调用也被拒绝，包含 TODO；仍然提出工具调用时不派发页面操作，反馈交回原有循环。
- [ ] 执行与验收请求额度隔离，执行框架请求、工具及纠正限制真实生效，所有请求共享原始 deadline_at，不增加专用总结请求或项目重试计数器。
- [ ] 正常最终文本仍可形成 Submission；持续调用、请求耗尽或超时而无最终文本时不伪造 Submission，Session 不启动验收。
- [ ] 真实浏览器动作加可控响应测试最后动作、多调用响应、继续调用及正常总结；不依赖 fill_value、scroll 或 wait 即可证明公共规则。
