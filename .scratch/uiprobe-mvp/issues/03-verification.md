# 03: 用断言与最终截图完成独立视觉验收

**What to build:** 调用方提供完整用例和一张已有最终截图，独立验收模型仅接收断言与该图片，返回逐项判断，程序校验后合成 Verdict，并单独保存验收输入、输出和纠正过程。

**Blocked by:** 01 — 非法输入返回可追查的会话错误。

**Status:** ready-for-agent

- [ ] 实际请求捕获证明 execution、TODO、执行历史和 Submission 均未发送；同次验收全部断言使用同一张图片。
- [ ] 结果 ID 与输入断言一一对应、状态合法、依据非空；程序补 screenshot_id 并按任一 failed、全部 passed、其余 error 的规则合成总状态。
- [ ] 合法 failed 或 error 不重试；格式错误只在验收请求／纠正额度和共享截止时间内纠正，不重置时限。
- [ ] 最终无完整合法输出、拒答、传输故障或超时时，为全部断言生成明确 error，不接受部分判断；没有截图或剩余时间时不请求模型。
- [ ] 验收记录独立于执行历史并引用已有 PNG；本地写入失败上报记录故障，不伪装成视觉判断。
- [ ] 模型构造依赖与每次运行的额度／记录依赖明确隔离；可控模型测试覆盖请求隔离、映射、合成及错误路径。
