# 04: 创建计划后按截图坐标点击并观察结果

**What to build:** Agent 先创建有效 TODO，再点击当前截图中的位置；一次操作经过预检、占用动作额度、实际派发、截图、保存及观察更新，模型随后可根据新图提交。

**Blocked by:** 02 — 从初始页面观察直接提交零动作会话。

**Status:** ready-for-agent

- [ ] 首次动作前必须成功创建非空计划；描述非空白、状态合法、最多一项 in_progress；之后可清空，未完成 TODO 不阻止提交。
- [ ] click 只接受当前 screenshot_id 及严格非负整数坐标，拒绝未知字段；旧图和越界等可预检问题不占动作额度。
- [ ] 使用图片像素与同次 CSS 视口比例换算，非 1:1 比例的真实浏览器场景验证点击目标正确。
- [ ] 预检通过后、实际派发前占用一次额度；派发前额度不足无操作，派发后故障仍计数且不重放。接合方式先补入正式设计。
- [ ] 操作、一次 capture、先保存 PNG 后引用、Context 更新和反馈处于同一串行区域；TODO 遵守框架浏览器屏障。
- [ ] 同响应两次 click 不会并发操作；第一动作更新图后第二次旧图被拒绝；工具开始／结束通过调用标识关联。
- [ ] 真实本地页面与可控模型测试完整证明计划到点击再提交路径，参数纠正使用框架机制，致命故障结束执行。
