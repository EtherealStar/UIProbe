# 01: 非法输入返回可追查的会话错误

**What to build:** 调用方提交测试 JSON 和配置后，非法内容返回安全、可定位字段的错误；在输出配置可用时保存独立运行结果。浏览器和模型不启动。有效输入可形成供后续会话使用的已准备数据。

**Blocked by:** None (can start immediately).

**Status:** completed

- [x] 测试对象严格接受 execution 与 assertions，拒绝未知字段、空白目标、空断言和重复 ID；配置预算拒绝字符串和布尔值冒充整数，聚合可确定的错误。
- [x] 非法 JSON 只报告可确定的解析问题，错误不包含原始秘密值；输入及配置失败时浏览器和模型调用次数均为零。
- [x] 合法输出配置下创建独占运行目录并保存事件和最终错误结果；目录冲突不覆盖，最终结果不会暴露半份写入。
- [x] 输出配置本身无效或写入失败时仍返回内存错误结果及已知可用产物路径，不宣称保存成功。
- [x] 截止时间与记录目录所需启动校验顺序在正式设计中明确；共享数据不依赖页面句柄、模型客户端或 Session 实现。
- [x] 可控测试证明以上行为，现有模型连接测试继续通过。
