# 08: 模型只看最新图片而本地保留完整执行证据

**What to build:** 多轮执行时模型每次只收到一张最新图片，完整文本和工具调用配对仍保留；调用方能从本地材料回查全部原生消息、截图、TODO 替换及动作事实。

**Blocked by:** 04 — 创建计划后按截图坐标点击并观察结果。

**Status:** ready-for-agent

- [ ] 在过滤前增量保存框架原生消息和所有图片关联，发送视图不覆盖完整历史，不建立另一套运行时消息协议。
- [ ] 至少三次观察的请求捕获证明每次只附加最新 PNG 一次，并紧邻图片编号、图片尺寸和 CSS 视口尺寸；历史文本和工具调用／结果配对不损坏。
- [ ] 本地产物能关联全部截图和动作，先保存图片再写引用；不同运行独占目录，完整历史不由最后一次过滤后的消息冒充。
- [ ] 每次有效 TODO 整表替换均有输入／结果记录，允许的并发遵守浏览器屏障，最终计划对应最近完成的有效替换。
- [ ] 不自动摘要或截断文本；容量不足明确失败；事件、工具结果及错误不回显实际引用值，真实 PNG 不保证脱敏。
- [ ] 行为测试同时验证实际模型请求和落盘产物，而不只检查 Context 内部字段。
