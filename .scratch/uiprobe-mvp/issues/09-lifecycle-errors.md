# 09: 超时取消及阶段故障后释放资源并保留已有结论

**What to build:** 运行在初始化、执行、验收或保存期间失败、超时或取消时，停止新业务操作，尽力保留证据和释放资源；调用方能区分断言结论与整次会话故障。

**Blocked by:** 02 — 从初始页面观察直接提交零动作会话；03 — 用断言与最终截图完成独立视觉验收；04 — 创建计划后按截图坐标点击并观察结果。

**Status:** ready-for-agent

- [ ] 从 run 入口建立的同一单调截止时间覆盖准备、初始化、执行和验收；截止后不发起新模型或页面操作。
- [ ] 执行失败、派发后故障、新页面、截图失败和本地 append 失败停止后续执行，不自动重放；无 Submission 不验收。
- [ ] 截图失败保留最近成功观察且不重新编号；已派发动作计数保留。
- [ ] 异常及超时后在独立短收尾时限内尝试 Browser 清理和保存；清理失败仍尝试最终保存，收尾不继续执行业务。
- [ ] 外部取消在收尾后继续传播，不正常返回并吞掉；借用模型客户端由应用入口管理。
- [ ] 验收已通过后清理／保存失败时 Session.status=error，已有 Submission 和 Verdict 不变；stop_reason 保留主原因，errors 保留多阶段错误。
- [ ] 最终保存失败仍提供内存结果和准确可用路径；目录冲突不覆盖；在线遥测关闭或不含敏感内容，导出失败不改变结论。
- [ ] 可控故障注入验证真实 Browser 生命周期与独立 Verification 路径；后续新增工具继续复用同一收尾契约。
