# 入口地址和测试数据由谁提供

Type: grilling
Label: wayfinder:grilling
Status: resolved
Blocked by: 01

## Question

用例只写“打开登录页面”和“输入正确的账号和密码”。运行时从哪里获得入口地址、正常状态的测试账号，以及用于验收的站点信息？模型和执行器分别需要看到哪些数据？

## Comments

用户在确认截图坐标约定时，已确认由运行程序提供入口地址和测试账号。

## Answer

运行程序提供入口地址和测试数据。Agent 在输入动作中引用数据名，由执行器取值输入，记录中保留引用名。站点验收依据的来源已在[两种断言如何给出用例结论](04-verdict.md)中确定。本条补记此前的决定。
