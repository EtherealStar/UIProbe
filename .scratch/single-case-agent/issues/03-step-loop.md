# 谁控制每次动作和运行终止

Type: grilling
Label: wayfinder:grilling
Status: resolved
Assignee: rowla
Blocked by: 01, 02

## Question

如何定义一次决策、一次浏览器动作与一次重试？由谁检查动作参数和页面状态，如何计步、处理超时和提出验收？

## Answer

程序打开入口页，取得初始截图。之后一轮决策计一步，每轮至多执行一个动作。程序根据动作的 JSON Schema 检查参数，并为坐标动作校验截图标识及边界。等待、引用旧图和坐标越界均占用该轮步数。程序将动作结果或校验错误反馈给执行 Agent，执行浏览器动作后追加最新截图。

执行 Agent 看到首页或明确的登录错误均可请求验收。验证器依据原始预期给出结果。等待页面变化时可以请求短暂等待后重新截图。执行器掌管整次运行的超时与最大步数；预算耗尽仍未得出验收结论时，记为 `error`，保存最后截图与停止原因。
