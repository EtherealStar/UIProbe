# 08: 硬截止时间与取消快照跨批次收尾

**What to build:** 运行到期或被外部取消后，系统停止全部业务请求、释放资源并保存已有证据；Suite 接收被取消 Case 的完整内存快照后标记后条未运行，完成收尾再继续传播取消。

**Blocked by:** 03 整批预检后串行运行并隔离 Case 配置；04 同一循环逐段提交并有界异步验收.

**Status:** completed

- [x] 整批预检不占某条 Case 时限；每 Session 从启动建立唯一单调 deadline，初始化、执行、排队及验收共享，阶段、提交和执行结束均不续时。
- [x] 到期后无新业务请求或动作，全部任务退出；排队及运行中的已接受提交收敛为 finished／error，已完成 Verdict 保持。
- [x] Session 通过携带最终 SessionResult 的专用 asyncio.CancelledError 子类交付快照；取消仍是控制流，不进入 RunError、不正常返回。
- [x] Suite 接收内存快照保留已运行条目和证据，后续合法项为 not_run，关闭共享资源、保存可用批次事实后继续传播取消；不依赖磁盘重建或轮询。
- [x] 覆盖执行、排队、验收、Browser 关闭、最终保存期间取消及再次取消；Session 外取消不伪造 Session，主取消不被资源关闭故障覆盖。
- [x] 清理和保存采用独立短时限，不追加业务时间；最终线程只处理独立快照，超时及迟到完成不能修改已交付对象或声称保存已成功。
- [x] 真实本地 Browser 释放、模型请求顺序、取消传播和有界退出经受控同步点验证；最终无 queued／running 或遗留业务任务。
