# 04: 同一循环逐段提交并有界异步验收

**What to build:** 执行 Agent 在同一 Case 的一次持续循环中逐段获知检查点，通过回执推进，并在已提交证据后台验收时继续后续页面操作；排队、并发及乱序完成都不会改变证据或报告顺序。

**Blocked by:** 02 新格式单检查点显式提交并返回批次结果.

**Status:** completed

- [x] 每 Case 只调用一次 execute，Context 初始只包含第一阶段；下一阶段仅由成功回执公开，TODO、历史和整条 Case 预算持续保留。
- [x] 未来阶段在公开前不出现在 prompt、历史、工具参数枚举、说明或拒绝反馈；验收结论不进入执行模型。
- [x] 提交只绑定最新已保存观察，不重拍或隐式等待；多个检查点可复用同图，保存／登记失败不得回执成功或推进。
- [x] 未知、非当前、重复提交可纠正拒绝且不创建任务；回执交付失败不撤销已成立提交、不重复验收。
- [x] 同响应动作后提交取得新图；成功提交后的剩余浏览器动作及再次提交拒绝，下一轮读取回执后才继续；最后阶段后全部工具禁用。
- [x] 验收并发默认 1 且遵循配置上限；用受控同步点证明回执不等待槽位、下一阶段操作与已有验收重叠，并覆盖上限 2 和乱序完成。
- [x] 验收只接收本组冻结断言和截图，后续页面变化不修改证据；材料互不覆盖，最终检查点结果按声明顺序。
- [x] 执行退出即开始 Browser 清理，返回前执行、全部验收及清理均已收敛；无 queued／running 或返回后验收写入，真实本地页面及原生受控模型回归通过。
