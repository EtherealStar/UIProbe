# 06: 执行和单项验收故障各自收敛

**What to build:** 某个检查点判断失败或验收模型故障时，其他工作继续；执行提前结束或故障后，已有提交仍在原截止时间内完成验收。页面在执行退出后释放，报告清楚保留已完成、未提交和尚未到达的事实。

**Blocked by:** 04 同一循环逐段提交并有界异步验收.

**Status:** completed

- [x] 合法 failed 或证据不足 error 不重试到通过，不触发返工、不传回执行历史、不取消兄弟验收或后续执行。
- [x] 单项最终模型／无效完整输出故障为本提交全部断言形成系统 error 及关联 RunError；不接受部分输出，不取消同级。
- [x] 执行模型或派发后故障终止执行、不重放动作，已成立提交在原 deadline 内继续验收，无须正常 ExecutionOutcome。
- [x] 提前最终文本不补交：当前阶段 not_submitted、未来阶段 not_reached 且没有伪造 Verdict；初始化未公开阶段可全为 not_reached。
- [x] 执行及工具退出后立即开始 Browser 关闭，与剩余验收重叠；关闭失败增加 Case 故障但不取消冻结证据验收。
- [x] stop_reason 保留实际执行停止原因，后续验收／清理故障不覆盖；已有合法 Verdict、文本、动作数和截图保持，最终状态按契约优先级合成。
- [x] 受控慢验收跨越执行故障及 Browser 关闭后仍正确完成；真实本地浏览器和受控模型验证最终无活动检查点状态或遗留任务。
