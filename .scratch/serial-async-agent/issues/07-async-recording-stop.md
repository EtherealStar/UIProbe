# 07: 后台记录故障主动停止当前及后续 Case

**What to build:** 后台验收的必要本地材料保存失败时，系统立即停止当前 Case 的执行和其他验收，保留已有事实，并停止后续 Case；调用方能分清主故障、后续收尾失败及实际可用产物。

**Blocked by:** 03 整批预检后串行运行并隔离 Case 配置；04 同一循环逐段提交并有界异步验收.

**Status:** completed

- [x] 验收请求视图、响应、诊断、最终历史及提交登记等必要记录故障，通过 Session 私有通知主动唤醒等待中的执行控制，不等结束时才扫描错误列表。
- [x] 通知后停止调度、取消并等待执行及全部验收退出，不再发起模型请求或页面动作；后台故障不伪装成可纠正工具拒绝。
- [x] 已完成合法 Verdict 保留；已接受但未完成提交收敛为 finished／系统 error；未提交和未到达阶段保持真实状态。
- [x] Suite 将后续合法条目标为 not_run，保留原输入错误及已运行项，批次为 error；不自动重跑。
- [x] 故障处置再次遇到记录、诊断、清理或结果保存失败时，保留原始 error_id、stop_reason 和已有事实，追加可取得的独立摘要，不递归依赖失败记录。
- [x] 返回内存结果与实际可用路径；未成功保存的最终文件不宣称可用，返回后没有业务验收或结果修改。
- [x] 执行请求被受控阻塞时注入后台写入失败，验证即时取消、后条不启动及无遗留任务；对照在线 exporter 失败只标观测不完整且继续业务。
